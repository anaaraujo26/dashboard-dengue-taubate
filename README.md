# Dashboard de Dengue no Power BI

## Sobre o projeto

Este projeto apresenta um dashboard interativo desenvolvido no Microsoft Power BI para análise de casos notificados de dengue entre 2015 e 2026.

O painel permite analisar:

- evolução anual dos casos;
- sazonalidade mensal;
- distribuição por faixa etária;
- distribuição por sexo;
- evolução dos desfechos dos casos;
- resultados filtrados por ano.

## Estrutura do dashboard

O dashboard possui duas páginas:

### Página 1 — Sazonalidade e Tendências Temporais

Apresenta:

- total de casos notificados;
- casos registrados em 2024;
- média anual de casos;
- evolução anual;
- distribuição mensal;
- filtro por ano.

### Visualização da Página 1
![Dashboard Dengue - Sazonalidade e Tendências Temporais](dashboard_pagina1.png)

### Página 2 — Perfil Demográfico e Gravidade

Apresenta:

- casos por faixa etária;
- distribuição por sexo;
- evolução dos casos;
- filtro interativo por ano.
